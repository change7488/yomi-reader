# Yomi Reader v0.3.1 · Android 文件夹导入闪退修复

这是 v0.3.0 的稳定性补丁，重点处理部分 Android 机型在“选择文件夹 → 递归扫描 → 批量导入”过程中直接退出、卡死或文件管理器无响应的问题。Windows 端同步获得更轻量的文件列表预览与分批导入。

## 下载

- **Windows x64**：`Yomi-Reader-0.3.1-x64-Setup.exe`
- **Android ARM64**：`Yomi-Reader-Android-arm64-debug.apk`（仍为测试签名）
- **SHA256SUMS.txt**：两端安装包的 SHA-256 校验值

## 修复内容

- Android 系统文件夹扫描改成有限深度的广度优先遍历，避免非常深的子目录递归导致异常。每次最多返回 1200 条匹配书籍，扫描规模过大时会提醒选择较小子目录。
- 文件夹元数据读取及多文件选择器的查询交给后台线程处理，降低 Android 主线程阻塞风险。
- 原生文档读取改用 `openRead → readChunk → closeRead`，每次约 128 KB；**不再一次性把整本书变成巨大的 Base64 消息**，异常时自动关闭文件句柄。
- EPUB/TXT/PDF 文件夹扫描结果默认全选；界面一次只显示 60 条，可展开更多条目，支持单项取消、全选/取消全选和格式过滤。
- 批量导入分批执行（Android 每批最多 16 本，Windows 每批最多 50 本），单批完成后可以继续导入剩余的书，不会因重绘过多书目而卡顿。
- 默认 SHA-256 跳过重复内容；旧书、已读进度、自定义字体和笔记保留。
- 增加文件列表分页测试、文件流异常关闭测试和 Windows 界面回归检查。

## 限制与安装提醒

**Android 单个文件暂时限制为 64 MB**，以避免设备内存不足。大型文档仍然需要后续真正的原生增量解析支持。本补丁基于代码风险点做针对性修复，通过自动构建并不代表已经覆盖全部厂商文件管理器；如果仍闪退，请在 Issues 反馈 Android 型号、Android 版本、文件夹大致数量及闪退发生在哪一步。

**非常重要：APK 仍为 GitHub Actions 产生的 debug 签名，不保证能覆盖安装旧 APK！** 手机中已有的阅读记录和导入书籍保存在应用本地沙盒，卸载可能彻底清空。**不要因签名冲突直接卸载旧版**；先保留旧版及原始电子书，待后续提供固定签名与可靠的备份迁移方案。

Windows 原有书库、安装目录和用户资料标识保持不变。完整项目说明见 [README](https://github.com/change7488/yomi-reader#readme) 与 [更新日志](https://github.com/change7488/yomi-reader/blob/main/CHANGELOG.md)。
