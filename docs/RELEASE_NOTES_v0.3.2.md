# Yomi Reader v0.3.2 · 桌面阅读工作区与漫画 PDF

本预览版加入独立桌面阅读窗口和 PDF 漫画阅读模式，并继续沿用原有书库数据库、书籍实体和阅读进度。

## 新增

- Windows 书库与阅读器使用独立窗口。打开多本书会复用阅读窗口的标签页，可拖动排序、关闭、恢复最近关闭的标签，并选择下次启动时恢复阅读工作区。
- 书库窗口和阅读窗口分别保存位置、尺寸与最大化状态；关闭阅读窗口前会先保存阅读进度。
- Windows 与 Android 共用离线 PDF.js 阅读器，提供连续滚动、单页阅读、双页漫画、单独显示封面、日漫从右向左、从上到下滚动和附近页面缩略图。
- PDF 增加自动、标准、高清和超清渲染档位、页面缩放、间距及跳转撤回。渲染采样不会生成原稿没有的细节，Canvas 受设备像素预算限制。
- 首页/书库、设置、阅读位置与现有 TXT、EPUB 功能保留。

## 更新与兼容性

- 不升级、不清空 IndexedDB，不迁移书籍文件；阅读工作区快照只保存书籍 ID 和标签顺序。
- PDF.js 和 Worker 在桌面启动、测试及打包时从锁定依赖自动同步，无需复制文件。
- Windows 安装包尚未进行商业代码签名。
- Android APK 是 GitHub Actions 生成的 debug 签名预览包。签名可能与旧版不同，卸载可能清空书库；请先备份书籍与阅读数据。

- 本机未配置 JDK 21 和 Android SDK，也未进行 Android 真机回归；请参考 GitHub Actions 的构建结果，不要把自动构建当成所有设备均已兼容的证明。
